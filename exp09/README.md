## 🎨 Features

- Dark minimal aesthetic (black/gray theme)
- Google Fonts (Inter)
- Glassmorphism navigation with backdrop blur
- Gradient accents and glow effects
- Smooth CSS animations (fade-in)
- Hover effects on buttons and cards
- Fully responsive (mobile-first)
- Modern table design with alternating rows
- Sticky navbar

## 💻 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks used - pure custom implementation.

## 🚀 Getting Started

1. Clone or download the repository
2. Open `index.html` in any web browser

```
/
├── index.html
├── about.html

```
